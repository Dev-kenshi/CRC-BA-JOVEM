# CRC Jovem BA: proposta de site

**PROPOSTA.** Versão de demonstração, sem aprovação da comissão. Não é o site oficial.

Site estático, sem chave e sem servidor: Terra 3D com a Bahia e as subcomissões, eventos com contagem, Exame de Suficiência com fonte, inscrição com QR Code, gerador de cartão para Feed e Stories, assistente que responde com dados oficiais e trilha do estudante.

O que ainda precisa de validação da comissão está marcado no próprio site como "a validar pela comissão".

As páginas pedem para não aparecer em buscadores (`noindex` e `robots.txt`).
